# Lab-Exercise-6

1. Solution Ideation – Crazy 8s

UX Problem: Booking a hospital appointment is confusing and time-consuming.

Crazy 8s – 8 Ideas:

Quick Book – Book an appointment from the home screen.
Doctor Search – Search doctors by name/specialization.
Specialty Selection – Choose department like Cardiology, ENT, etc.
Available Slots – Show only available time slots.
Emergency Button – Quick access to emergency services.
Smart Reminder – Remind users about upcoming appointments.
Map & Navigation – Show hospital location and route.
Online Consultation – Allow video consultation with doctors.

Best idea: Quick Book + Doctor Search + Available Slots in one simple flow.

2. Creating User Stories
User Stories
As a patient, I want to search for doctors, so that I can find the right doctor easily.
As a patient, I want to view available appointment slots, so that I can choose a convenient time.
As a patient, I want to book an appointment online, so that I can avoid waiting at the hospital.
As a patient, I want to receive appointment reminders, so that I don't miss my appointment.
As a patient, I want to cancel or reschedule my appointment, so that I can change my plans when necessary.
3. Creating Scenarios
Selected User Story

As a patient, I want to book an appointment online, so that I can avoid waiting at the hospital.

Scenario

User: Ravi, a college student
Goal: Book an appointment with a doctor.

Ravi is feeling unwell and needs to visit a hospital. He is at home using his mobile phone. He feels worried and slightly stressed because he does not want to wait for a long time at the hospital.

He opens the hospital app and searches for a doctor. He selects the required department and chooses a doctor. The app displays available dates and time slots. Ravi selects a convenient slot and enters his basic details.

After confirming the appointment, he receives a confirmation message and reminder.

Emotional Journey:

😟 Worried → 🔍 Searching → 🙂 Relieved → ✅ Satisfied

Environment: At home, using a smartphone with an internet connection.
